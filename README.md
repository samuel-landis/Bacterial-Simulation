# Bacterial-Simulation


This simulation is designed to replicate the interactions of competing bacteria within a petri dish environmen, allowing for the study of how environmental factors influence bacterial behavior and competition.
It was inspired by https://www.quantamagazine.org/biodiversity-may-thrive-through-games-of-rock-paper-scissors-20200305/
